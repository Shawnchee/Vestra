Findings

Critical · credential hygiene

Rotate the Gemini key before publishing

The key was shared in chat. It is ignored by Git and was not found in tracked files, but treat it as exposed before any public demo or repository release.

Fix: create a replacement key in Google AI Studio, restrict it to the Gemini API and suitable quota limits, replace the value in the ignored .env.local, then revoke the old key. Never put the replacement in client code, a submission form, or a commit.

High · Public AI usage

Monitor Gemini quota on the public demo

Vestra no longer has an application-level request limiter. Anyone with access to the public demo can trigger Gemini-backed debate and audio requests, subject to Gemini's project quotas and limits.

Mitigation: keep the Gemini key server-side, review usage in Google AI Studio, and disable or rotate the key if usage is unexpected. This is an accepted hackathon tradeoff, not a production abuse-control design.

Medium · automated coverage

Add automated checks for the most important data rules

The current package has lint and build scripts but no test script. Manual browser checks cover the main demo, but they will not catch future regressions in price calculations, candle normalization, or citation targets.

Fix: add unit tests for PreStocks parsing, premium calculation, OHLCV de-duplication, backtest execution/costs, and citation ID validation; add one browser flow covering asset → headlines → cited debate → replay.

Changes made during review

  • Debate requests are limited to 16 KB, compare the browser origin against the proxy-forwarded host, and resolve the company and market snapshot from the PreStocks catalogue on the server.
  • Market history accepts only an exact mint returned by the PreStocks catalogue, not arbitrary token addresses.
  • Gemini instructions now treat incoming headlines as untrusted source text and explicitly separate market values from headline evidence.
  • PreStocks and Google News responses are capped at 2 MB; the Gemini call deadline is aligned with the browser’s overall wait window.
  • Research now renders six headlines because the AI can cite the sixth item.
  • 30D/90D chart windows now filter by calendar time. The strategy uses the full fetched pool history and says missing pool days can make the 5/20-day rule span more calendar days.
  • Debate and audio routes retain request validation, origin checks, bounded request sizes, timeouts, and provider error handling. No separate application rate limiter is enabled.

What was verified

  • npm run lint, npm run build, and git diff --check passed after these changes.
  • Two live three-role debates completed, including one during final QA after correcting proxy-origin handling and company-name normalization. Bull and Editor used gemini-3.5-flash-lite; Bear used fallback gemini-3.1-flash-lite. An intervening request returned the recoverable provider-busy state.
  • The sixth cited headline now exists in the DOM. Research has no horizontal overflow at 375, 768, and 1280px.
  • Market replay resolved the selected catalogue mint to a GeckoTerminal USDC pool and drew daily Vela candles. CoinDesk stories stayed in their separate context panel.
  • Anthropic was selected as the clean-start demo asset after a latest QA check found its daily pool close near the PreStocks quote, about $45K liquidity, and about $272K 24-hour volume. SpaceX showed a much larger gap (about 412%) and about $28 of 24-hour volume. These time-sensitive readings do not make the pool a PreStocks return series.
